# 🚀 Portafolio Personal

Bienvenido a mi portafolio web. Este proyecto fue desarrollado con el objetivo de presentar mi perfil profesional, experiencia, formación académica, habilidades técnicas y proyectos realizados en el área de desarrollo de software.

## 🌐 Demo

Puedes visitar el portafolio en el siguiente enlace:

## 📖 Sobre el Proyecto

Este portafolio fue diseñado y desarrollado para mostrar mis conocimientos, experiencia y proyectos como desarrollador de software en formación. La aplicación cuenta con una interfaz moderna, adaptable a diferentes dispositivos y orientada a brindar una experiencia de usuario clara y profesional.


2. Ingresa al directorio del proyecto:

```bash

```

3. Abre el archivo `index.html` en tu navegador.
